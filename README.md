# Healthcare Appointment System

## SDC Requirements
- HTML, CSS and JavaScript only
- CSS Grid and Flexbox
- User Module
- Admin Module
- Signup/Login using Local Storage
- Module-wise JavaScript navigation
- Local Storage as the only database
